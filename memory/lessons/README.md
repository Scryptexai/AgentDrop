# Pelajaran agent

Satu berkas per profil: `pekerja-harian.md`, `pekerja-quest.md`, dst.

Isi tiap berkas dua bagian:

1. **Buku besar metode** di paling atas — tabel satu metode satu baris, status
   `BEKERJA` / `GAGAL` / `BELUM DIUJI` / `USANG`. Inilah jawaban atas "metode
   mana yang sudah terbukti jalan".
2. **Entri harian** di bawahnya — append-only, satu pelajaran per entri.

Format lengkap dan protokolnya ada di `skills/self-improvement/SKILL.md`.

**Jangan menaruh secret di sini.** Berkas ini bisa terbaca oleh agent lain.
